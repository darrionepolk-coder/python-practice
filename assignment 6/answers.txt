Question 1: Which loop is better for writing the temperature records, and why?

I think the for-loop is better for this program because we already know the range of numbers we need to go through. The range function makes it easier to go from 0 up to the Celsius temperature entered by the user. A while-loop can do the same thing, but we have to manually increase the counter each time. The for-loop is simpler and easier to follow when working with a known range.

Question 2: Which loop is better for searching the temperature file, and why?

I think the for-loop is better for searching through the file because it automatically reads each line until it reaches the end of the file. This makes the code easier to understand and prevents us from having to manually read the next line each time. A while-loop also works, but it requires more steps because we have to read each line and check when the file reaches the end.
